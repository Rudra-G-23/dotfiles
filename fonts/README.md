# Fonts & Theme

Current setup (09-07-2026):
- Font: JetBrains Mono Nerd Font
- Theme: Dark Modern

Used in both VS Code (`vscode/settings.json`) and WezTerm (`wezterm/wezterm.lua`).

## Install

1. Download: https://www.programmingfonts.org/#jetbrainsmono
2. Install it locally so both VS Code and the terminal can use it.
3. Open VS Code and confirm `editor.fontFamily` / `terminal.integrated.fontFamily` point to it.
